## Background

After T03/T03b, sheets can be edited but nothing can leave the app. T04 makes FrameSheet a usable contact-sheet tool: saving the sheet as an image with its header, saving single thumbs, and the PNG/JSON round trip that also reads MoviePrint 0.2.x files. Owner decisions that apply: sheets are named `Sheet-N` and the file-name token is `[SN]` with `[MPN]` as an alias (decision 24); Save is a download button in the window toolbar, no footer (decision 23); the header shows the FrameSheet app icon instead of MoviePrint's logo (§5.2).

## Goal

The owner can save the current sheet as PNG or JPG with an optional header, at the chosen size and file name, save single and individual thumbs, export and import the sheet as JSON or PNG with embedded data (FrameSheet v3 and MoviePrint 0.2.x), and relink a moved movie.

## Scope

### In scope

1. **Naming (core):** rename `MoviePrint-N` to `Sheet-N` in code, with a migration for libraries saved under the old names only if trivial (otherwise leave old names as they are); naming scheme with tokens `[MN]` `[ME]` `[SN]` (`[MPN]` alias) `[FN]` `[TC]`, sanitising and " edit N" (§6); tests.
2. **Print header (§5.2):** app icon, file name, optional folder path, details line and mini timeline with IN/OUT and thumb positions; Show header toggle in the sheet toolbar and the Styling section with its three sub-options (§6, §4); header geometry from §5.1; drawn the same in the window and in the saved image.
3. **Output section (§6)** in the right panel: folder (Desktop default, Change…, Same as movie file), size 1024–16384 in 1024 steps plus max with the "(×H px)" label, PNG/JPG and quality, background colour (alpha in PNG only), save options (Overwrite, Include individual thumbs, Embed frame numbers, Embed file path, Open Finder after saving), thumb format and quality, naming scheme fields with live preview and the missing-`[FN]`/`[TC]` warning.
4. **Save MoviePrint (§12):** download button in the window toolbar (key M) with a menu (Open output location; Save All stays for T08); offscreen render of the grid at the target width with frames decoded fresh at about 2× thumb size, capped at the original, through the existing `DecodeGate`; progress and Cancel; limit 16384 px. **Save thumb** in the hover overlay (original resolution) and **Include individual thumbs** (a folder named after the print).
5. **Embedded data and JSON (§12):** PNG `tEXt` chunks before IEND with MoviePrint's keys (`version`, `filePath` URI-encoded, `transformObject`, `columnCount`, `frameNumberArray`); sheet menu Export JSON (`<file>-<sheet>.json`). Core library writes and reads both; tests include a round trip and a sample in MoviePrint 0.2.x's format built from its source (`app/utils/utils.js`, `app/components/...` in fakob/MoviePrint_v004; MIT).
6. **Import (§12, §4):** header "more options" → Import (PNG with embedded data, or JSON) → new movie entry and interval sheet; rotation ignored; missing movie handled with Locate. Movie menu **Replace movie** (relink, keeping sheets). **Clear movie list** in the same "more options" menu, with confirmation and undo.
