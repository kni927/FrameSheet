## Background

A read-only Codex audit of commit 89b5d7f (Google Drive `AI/Handoff/FrameSheet/codex-audit-20261105-01.md`; app code unchanged on `main` since) reported 16 findings, traced in code but not reproduced (its `swift test` could not run in its sandbox). The findings, as written by Codex:

1. blocker — A failed library load destroys the original library on quit. `Sources/FrameSheet/AppModel.swift:216`, `Sources/FrameSheet/FrameSheetApp.swift:98`. A decoding failure leaves an empty library attached to the original store; quitting unconditionally saves it over the unreadable file. Fix: disable persistence after a failed load until recovery succeeds or the user explicitly chooses a replacement library.
2. should fix — Process cancellation can still hold DecodeGate indefinitely. `Sources/FrameSheetCore/Scan/RawVideoPipe.swift:98`, `Sources/FrameSheetCore/Decode/ProcessRunner.swift:79`. Raw-video cancellation sends SIGTERM, but its SIGKILL fallback runs only after the blocked read returns; ProcessRunner sends only SIGTERM before unbounded pipe/exit waits. Fix: termination escalation independent of the reading queue, bounded waits, forced-kill fallback.
3. should fix — Replacing a movie during a scan stores the old movie's results against the replacement. `Sources/FrameSheet/AppModel.swift:696`, `Sources/FrameSheet/MovieListView.swift:96`. Fix: cancel and await active scan producers before relinking; reject results whose source generation changed.
4. should fix — In-flight thumbnail loads undo transform-cache invalidation. `Sources/FrameSheet/AppModel.swift:1513`, `Sources/FrameSheet/AppModel+Transform.swift:62`. Fix: tie decode tasks and cache writes to a source/transform generation; discard stale results.
5. should fix — Duplicating a shot sheet deletes all its scenes. `Sources/FrameSheetCore/Editing/IntervalEditing.swift:256` (`copy.scenes = []`). Fix: copy scenes and remap scene IDs to the new thumb IDs.
6. should fix — "These thumbs" face scans cache another frame's faces under the requested number. `Sources/FrameSheetCore/Faces/FaceScanner.swift:360` (`runSingleFrames` ignores `actualFrame`/`isExact`). Fix: reject inexact results; leave those frames unanalyzed.
7. should fix — Saved PNG metadata can identify different frames from its pixels. `Sources/FrameSheet/AppModel+Save.swift:284`. Fix: build embedded data from the same corrected sheet snapshot used for rendering.
8. should fix — Reusing an inexact cached image produces an incorrect label without a marker. `Sources/FrameSheet/AppModel.swift:1480`, `:1527`. Fix: carry actual-frame metadata through every cache lookup for labels and markers.
9. should fix — Failed decodes are accepted as exact edits. `Sources/FrameSheet/AppModel.swift:1270`, `Sources/FrameSheet/PlayerController.swift:620`. Fix: decode failure = refusal; keep the previous frame; show the error.
10. should fix — Aspect-ratio overrides crop sheet images instead of stretching them. `Sources/FrameSheet/PrintView.swift:151`, `Sources/FrameSheet/ScrubOverlay.swift:155`. Differs from decision 26. Fix: stretch to the display ratio before any timeline-box cropping.
11. should fix — Numeric fields in imported JSON/PNG can crash the app. `Sources/FrameSheetCore/Export/SheetExchange.swift:311`, `:331` (unchecked Double→Int, e.g. `"frameNumberArray":[1e100]`). Fix: validate bounds before conversion.
12. should fix — FFmpeg-routed decoding bypasses DecodeGate. `Sources/FrameSheetCore/Decode/FFmpegBackend.swift:175`, `:252` (batch allows five concurrent requests). Fix: gate public extraction; an internal already-gated path for AVFoundation fallback calls.
13. should fix — The player labels the pending frame while displaying the previous still. `Sources/FrameSheet/PlayerController.swift:225`, `Sources/FrameSheet/PlayerView.swift:457`. Fix: label the displayed still's frame and show the pending target separately.
14. should fix — Save All reports incomplete prints as successful. `Sources/FrameSheet/AppModel+Save.swift:187`. Fix: propagate partial-save warnings into the Save All report.
15. should fix — A final long scene adds an empty timeline row. `Sources/FrameSheetCore/TimelineGeometry.swift:67`. Fix: append the final row only when `inRow` is nonempty.
16. later — "Overwrite off" overwrites after exhausting collision names (`edit 999`). `Sources/FrameSheetCore/Export/FileNaming.swift:96`. Fix: continue until an unused name exists or return an error.
